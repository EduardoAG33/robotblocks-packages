# Demo de distancia

Paquete incluido mediante una lista explícita de IDs. Declara un sensor con ranura de bus `i2c` y otro con ranuras `trig` (salida digital) y `echo` (entrada digital). El bloque elige cualquiera por su capacidad `distance`; las asignaciones usan nombres de ranura.

No contiene hardware, datos simulados de sensores ni drivers.
Los descriptores son ejemplos ficticios; no representan un HC-SR04 con prueba física.
